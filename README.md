# AEVON 협찬 랜딩페이지 (1차 검수용)

- `index.html`: 모바일 우선 반응형 페이지 (외부 JS 빌드/서비스 불필요)
- `assets/`: 사용자가 제공한 제품 원본 이미지 5장, 크롭 또는 리터칭 없음
- 작동 기능: 사용설명서 3종 전환, 이미지 확대 및 닫기, 모바일/PC 반응형
- `python3 -m http.server 8080` 후 http://localhost:8080 확인
- GitHub Pages 사용 시 저장소 루트에 파일을 그대로 업로드한 뒤 Pages를 main/root로 설정
- AEVON 공식 홈페이지 저장소와 혼합하지 않음

## 현재 미확정 정보
AEVON 협찬 원고료, 제품 제공 방식, 콘텐츠 제작 기한, 게시물 유지 기간, 2차 활용 정책, 공식 DM/신청 링크는 제공되지 않아 임의 입력하지 않았습니다.
ChatGPT 연동 및 제품 기능·사양은 첨부된 홍보 자료의 설명일 뿐 실제 동작 여부를 검증하지 않았습니다.
